# 🌍 Countries Explorer

A responsive web application built with React, Vite, and TypeScript for exploring country information.

[![Live Demo](https://img.shields.io/badge/Live_Demo-View-green?style=for-the-badge&logo=vercel)](https://countries-explorer-ten.vercel.app/)
[![GitHub Repo](https://img.shields.io/badge/GitHub-Repository-blue?style=for-the-badge&logo=github)](https://github.com/KrishnaWanusha/countries-explorer)

## ✨ Features

- 🔍 Search countries by name
- 🌐 Filter by region (Africa, Americas, Asia, Europe, Oceania)
- 📱 Fully responsive design
- 🌓 Light/Dark mode toggle
- ⚡ Fast loading with Vite
- 🛠 Type-safe with TypeScript

## 🛠 Tech Stack

**Frontend:**

- React 18
- TypeScript
- Vite
- CSS Modules
- React Icons

**API:**

- [REST Countries API](https://restcountries.com/)

**Deployment:**

- Vercel

## 🚀 Getting Started

### Prerequisites

- Node.js (v16+ recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/KrishnaWanusha/countries-explorer.git
cd countries-explorer
npm install
npm run dev
```
